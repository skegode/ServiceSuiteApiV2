1. Authentication

All endpoints except /auth/token require a Bearer JWT in the Authorization header. Tokens are scoped to a specific entity — you can only access data belonging to your own organisation.

1.1 Get Access Token Public

POST/auth/token

Generates a JWT access token. Rate-limited to 5 requests per minute.

Request Body

{
  "clientId":     "your_client_id",
  "clientSecret": "your_client_secret",
  "entityId":     1
}
FieldTypeRequiredDescription
clientIdstringYesAPI client identifier provided by the admin
clientSecretstringYesAPI client secret
entityIdintegerYesYour organisation / entity ID

200 Success

{
  "success": true,
  "message": "Token generated successfully.",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "tokenType":   "Bearer",
    "expiresIn":   3600
  }
}
Include the token in every subsequent request: Authorization: Bearer <accessToken>

1.2 Create API Client Admin Only

POST/auth/clients

Provisions a new API client. Requires the X-Admin-Key header. Not for use by integrators — contact the ServiceSuite team.

Important: The clientSecret is only returned once. Store it securely immediately — it cannot be retrieved again.

2. Loans

All loan endpoints require Bearer JWT. The entityId is automatically derived from your token — you can only access your own entity's data.

2.1 Get Loans by Filter JWT

POST/loans/GetLoansByFilter

Returns active loans matching the supplied filter criteria. All filter fields are optional — omit any field to skip that filter.

Request Body

{
  "minDays":   30,
  "maxDays":   90,
  "minAmount": 5000,
  "maxAmount": 100000,
  "minOlb":    1000,
  "maxOlb":    50000
}
FieldTypeDescription
minDaysinteger?Minimum days past due
maxDaysinteger?Maximum days past due
minAmountdecimal?Minimum original disbursed amount
maxAmountdecimal?Maximum original disbursed amount
minOlbdecimal?Minimum outstanding loan balance
maxOlbdecimal?Maximum outstanding loan balance

200 Success — returns LoanResponse (count + array of LoanDto)

2.2 Get Active Loans JWT

GET/loans/ActiveLoans

Returns a list of active loans (balance > 0) with optional keyword search.

Query ParamTypeRequiredDefaultDescription
searchstringNo—Filter by borrower name, phone, or loan ID
topintegerNo20Maximum records to return
GET /loans/ActiveLoans?search=0712345678&top=50

3. Payments

3.1 Initiate M-Pesa STK Push JWT

POST/payments/stk-push

Triggers an M-Pesa STK push prompt on the customer's phone. M-Pesa credentials are configured per entity in the system database.

Request Body

{
  "amount":           2000,
  "phoneNumber":      "254712345678",
  "accountReference": "4501",
  "transactionDesc":  "Loan Repayment"
}
FieldTypeRequiredDescription
amountdecimalYesAmount to charge. Must be > 0
phoneNumberstringYesInternational format: 254XXXXXXXXX
accountReferencestringNoReference shown on the STK prompt (e.g. loan ID)
transactionDescstringNoDescription on the prompt. Defaults to "Payment"

200 Success

{
  "success": true,
  "message": "STK push initiated.",
  "data":    "ws_CO_16062024103400001234567890"
}
data contains the M-Pesa CheckoutRequestID. Use it to reconcile the payment when the M-Pesa callback arrives.

5. Fraud Analytics

All fraud endpoints require Bearer JWT and are scoped to your entity. Risk levels: High | Medium | Low.

5.1 Full Fraud Report JWT

GET/analytics/fraud/report

Runs all fraud signal queries in parallel and returns everything in one response. Use this for dashboard initial load.

200 Response shape

{
  "data": {
    "summary": {
      "highRiskAgentCount":      2,   "highRiskShopCount":       1,
      "duplicateIdentityCount":  3,   "loanStackingCount":       5,
      "zeroPaymentLoanCount":    8,   "estimatedFraudExposure":  320000.00,
      "generatedAt": "2024-06-16T10:00:00Z"
    },
    "agentSignals":        [ /* AgentFraudSignal[] */ ],
    "shopSignals":         [ /* ShopFraudSignal[] */  ],
    "duplicateIdentities": [ /* DuplicateIdentitySignal[] */ ],
    "loanStacking":        [ /* LoanStackingSignal[] */  ],
    "suspiciousLoans":     [ /* SuspiciousLoanSignal[] */ ],
    "paymentFraud": { "unpostedCount": 2, "unpostedAmount": 15000.00 }
  }
}

5.2 Agent Fraud Signals JWT

GET/analytics/fraud/agents

Flags collection agents with high default rates, write-off concentration, or arrears-heavy portfolios.

200 Sample record

{

GET/analytics/fraud/shops

Groups borrowers by onboarding agent (shop) and flags shops where the majority of clients are defaulting.

6. Webhooks

6.1 Spin Analysis Webhook Basic Auth

POST/webhooks/spin-analysis

Receives an analysis result from the Spin financial analysis service. Uses HTTP Basic Auth — not Bearer JWT.

Authorization: Basic <base64(username:password)>
Webhook credentials are configured server-side. Contact the ServiceSuite team to obtain the username and password.

Request Body

{
  "file_unique_id": "abc123xyz",
  "file_type":      "mpesa",
  "phone":          "0712345678",
  "id_number":      "30123456",
  "duration":       6.0,
  "json_data":      {},
  "timestamp":      "2024-06-16T10:00:00Z",
  "state_name":     "completed"
}
FieldTypeDescription
file_unique_idstringUnique ID of the analysed file
file_typestring"mpesa" or "bank"
phonestring?Phone number (M-Pesa statements)
id_numberstring?National ID
bank_namestring?Bank name (bank statements)
account_numberstring?Bank account number
durationdecimal?Statement period in months
json_dataobject?Raw analysis output from Spin
timestampdatetime?Time the analysis completed
state_namestring?e.g. "completed", "failed"

9. Code Examples

cURL — Full Flow

# Step 1 — Get token
TOKEN=$(curl -s -X POST \
  https://collectbox.servicesuitecloud.com/ServiceSuiteApiV2/auth/token \
  -H "Content-Type: application/json" \
  -d '{"clientId":"your_id","clientSecret":"your_secret","entityId":1}' \

# Step 2 — Client profile
curl -X GET \
  "https://collectbox.servicesuitecloud.com/ServiceSuiteApiV2/loans/borrower/profile?search=0712345678" \
  -H "Authorization: Bearer $TOKEN"

# Step 3 — STK push
curl -X POST \
  https://collectbox.servicesuitecloud.com/ServiceSuiteApiV2/payments/stk-push \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"amount":2000,"phoneNumber":"254712345678","accountReference":"4501"}'

# Step 4 — Fraud report
curl -X GET \
  https://collectbox.servicesuitecloud.com/ServiceSuiteApiV2/analytics/fraud/report \
  -H "Authorization: Bearer $TOKEN"

JavaScript (fetch)

const BASE = "https://collectbox.servicesuitecloud.com/ServiceSuiteApiV2";

async function getToken() {
  const res = await fetch(`${BASE}/auth/token`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ clientId: "your_id", clientSecret: "your_secret", entityId: 1 })
  });
  const { data } = await res.json();
  return data.accessToken;
}

async function apiGet(token, path) {
  return fetch(`${BASE}${path}`, {
    headers: { Authorization: `Bearer ${token}` }
  }).then(r => r.json());
}

// Usage
const token   = await getToken();
const profile = await apiGet(token, "/loans/borrower/profile?search=0712345678");
const overdue = await apiGet(token, "/loans/overdue?minDays=30");
const fraud   = await apiGet(token, "/analytics/fraud/report");

C# (HttpClient)

using var http = new HttpClient {
  BaseAddress = new Uri("https://collectbox.servicesuitecloud.com/ServiceSuiteApiV2/")
};

// Authenticate
var auth = await http.PostAsJsonAsync("auth/token",
  new { clientId = "your_id", clientSecret = "your_secret", entityId = 1 });
var token = (await auth.Content.ReadFromJsonAsync<ApiResponse<TokenResponse>>())!.Data!.AccessToken;
http.DefaultRequestHeaders.Authorization = new("Bearer", token);

// Call endpoints
var profile = await http.GetFromJsonAsync<ApiResponse<ClientProfileDto>>(
  "loans/borrower/profile?search=0712345678");
var fraud   = await http.GetFromJsonAsync<ApiResponse<FraudAnalyticsReport>>(
  "analytics/fraud/report");

PHP (cURL)

<?php
$base = "https://collectbox.servicesuitecloud.com/ServiceSuiteApiV2";

function apiPost($base, $token, $path, $body) {
  $ch = curl_init("$base$path");
  curl_setopt_array($ch, [
    CURLOPT_POST           => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => ["Authorization: Bearer $token", "Content-Type: application/json"],
    CURLOPT_POSTFIELDS     => json_encode($body)
  ]);
  $r = curl_exec($ch); curl_close($ch);
  return json_decode($r, true);
}

function apiGet($base, $token, $path) {
  $ch = curl_init("$base$path");
  curl_setopt_array($ch, [CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => ["Authorization: Bearer $token"]]);
  $r = curl_exec($ch); curl_close($ch);
  return json_decode($r, true);
}

$auth  = apiPost($base, "", "/auth/token",
         ["clientId"=>"your_id", "clientSecret"=>"your_secret", "entityId"=>1]);
$token = $auth["data"]["accessToken"];

$profile = apiGet($base, $token, "/loans/borrower/profile?search=0712345678");
$fraud   = apiGet($base, $token, "/analytics/fraud/report");
